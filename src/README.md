### 1. 프로젝트 개요

이 프로젝트는 보안 취약점 진단 및 방어 기법을 학습하기 위해 제작된 테스트 웹 서버입니다. 애플리케이션은 보안 적용 상태에 따라 총 5가지 레벨로 나뉘어 동작합니다.

* **Level 1 (매우 취약한 환경):** 어떠한 보안 검증도 적용되지 않아 SQL 인젝션, XSS(크로스 사이트 스크립팅) 등 대부분의 공격이 성공하는 상태입니다.
* **Level 2 (기초 검증 환경):** 기본적인 필터링이 적용되어 있으나, 우회 기법을 통해 공격이 가능한 상태입니다.
* **Level 3 (중간 방어 환경 / Low Risk):** 주요 기술적 취약점은 방어되었으나, 설계상의 논리적 허점이나 불충분한 검증으로 인한 공격이 가능한 상태입니다.
* **Level 4 (고도화 방어 환경 / Secure):** 다양한 시큐어 코딩 가이드라인이 적용되었지만, 특수한 조건에서 약간의 취약점이 발견될 수 있는 상태입니다.
* **Level 5 (완전 구현 및 암호화 환경 / Hardened):** 애플리케이션의 모든 데이터 흐름에 암호화가 적용되고 보안 표준을 준수하는 가장 안전한 상태입니다.

### 2. 사전 준비 사항 (필수 확인)

테스트 환경은 개발자의 PC 설정과 무관하게 독립적으로 실행되도록 Docker(도커)라는 가상화 기술을 사용합니다. 실행 전 반드시 아래 사항을 확인하십시오.

1. **Docker Desktop 설치:** PC에 Docker Desktop 프로그램이 설치되어 있어야 합니다.
2. **Docker 실행 상태 확인:** 단순히 프로그램을 설치한 것에 그치지 않고, **Docker Desktop 프로그램이 켜져 있어야 합니다.** 화면 우측 하단(시스템 트레이)에 Docker 아이콘이 실행 중 상태인지 반드시 확인하십시오.

### 3. 설치 및 실행 방법

복잡한 설정 없이 제공된 스크립트 또는 명령어를 통해 1분 이내에 서버와 데이터베이스가 자동 구축됩니다.

**방법 A: 제공된 실행 파일 사용 (권장)**

1. 배포받은 폴더 내에 있는 `start.bat` (Windows용) 파일을 더블 클릭하여 실행합니다.
2. 검은색 명령 프롬프트 창이 열리며 자동으로 설치 및 실행이 진행됩니다.

**방법 B: 수동 터미널(명령 프롬프트) 실행**

1. 배포받은 폴더 경로로 이동하여 명령 프롬프트(`cmd`) 또는 PowerShell을 엽니다.
2. 아래 명령어를 복사하여 붙여넣고 실행합니다.
```bash
docker-compose up --build -d

```

### 4. 웹 서비스 접속 및 테스트 계정

실행이 완료되면 웹 브라우저를 열고 아래 주소로 접속하여 테스트를 시작할 수 있습니다.

* **접속 주소:** `http://localhost:8080/`

### 5. 환경 초기화 (데이터베이스 복구)

테스트(Level 1~3) 중 SQL 인젝션 공격 등으로 데이터베이스가 훼손되거나 데이터가 삭제된 경우, 서버를 초기 백지상태로 되돌릴 수 있습니다.

1. 명령 프롬프트(`cmd`)를 열고 프로젝트 폴더 경로로 이동합니다.
2. 아래 명령어를 입력하여 기존 환경을 완전히 삭제합니다. (데이터베이스 포함)
```bash
docker-compose down -v

```


3. 다시 시작 스크립트(`start.bat`)를 실행하거나 `docker-compose up --build -d` 명령어를 입력하면 초기 데이터가 복구된 상태로 재실행됩니다.
